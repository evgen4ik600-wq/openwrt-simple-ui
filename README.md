# 🚀 EasyRoute for OpenWrt

> **Простая выборочная маршрутизация приложений, сайтов и устройств через AmneziaWG на OpenWrt — без ручной работы с nftables, fwmark, CIDR и policy routing.**

EasyRoute превращает сложную VPN-маршрутизацию OpenWrt в понятный интерфейс: пользователь выбирает **что** должно идти через VPN и **через какой AmneziaWG-профиль**, а техническую работу выполняет EasyRoute.

## 🤔 Какую проблему решает

Типичная задача: **YouTube, Telegram, ChatGPT и Instagram отправлять через VPN, а банки, российские сайты, игры и остальной интернет оставить напрямую.**

В обычном OpenWrt для этого приходится разбираться с AmneziaWG, firewall4/nftables, fwmark, routing tables, ip rule, CIDR, dnsmasq-full, nftset и обновлением доменных/IP-списков.

EasyRoute скрывает эту сложность. Для пользователя схема становится простой:

- 📺 YouTube → 🛡️ VPN
- ✈️ Telegram → 🛡️ VPN
- 🤖 ChatGPT → 🛡️ VPN
- 🏦 остальной интернет → 🌍 WAN

## ✨ Возможности

### 🧩 Каталог приложений

Готовые профили для YouTube, Telegram, ChatGPT/OpenAI, Instagram, Discord, TikTok, Twitch, Spotify, Claude и Facebook. EasyRoute автоматически создаёт доменные и IPv4/CIDR-списки и связывает их с выбранным VPN. Готовые сетевые списки сейчас получаются из OpenCCK.

### 🔄 Автообновление

URL-списки обновляются автоматически. Для сервисных списков используется интервал 24 часа. При временной ошибке источника предыдущий рабочий список сохраняется.

### 🛡️ Нативный AmneziaWG

EasyRoute использует обычные системные AmneziaWG-интерфейсы OpenWrt. VPN не запирается внутри приложения и продолжает существовать как стандартный сетевой интерфейс OpenWrt.

### 📱 Маршрутизация устройств

Можно отправить через VPN весь телефон, телевизор или компьютер. EasyRoute обнаруживает клиентов через DHCP/neighbor table — MAC-адрес не нужно искать вручную.

### 🟢 Простое управление

Маршруты включаются и выключаются переключателем. Основной интерфейс не показывает пользователю mark, routing table, nftset и другие технические параметры.

### 🩺 Самодиагностика

EasyRoute проверяет DNS/Интернет, AWG, firewall4, dnsmasq, policy routing и механизм обновления списков. Подробности доступны в разделе «Для опытных».

## 🧠 Как это работает

    Устройство
        │
        ▼
      OpenWrt
        │
        ├── обычный трафик ─────────────► WAN
        │
        └── выбранные сервисы/устройства
                    │
                    ▼
              nftables / fwmark
                    │
                    ▼
               routing table
                    │
                    ▼
               AmneziaWG VPN

Для доменной маршрутизации используется связка **dnsmasq-full + nftset + firewall4/nftables**. Для VPN-политик — fwmark и отдельные routing tables.

## 🛡️ Безопасность

Перед применением сгенерированной firewall-конфигурации EasyRoute запускает проверку firewall4. При ошибке новые файлы откатываются.

EasyRoute использует собственные namespaced nftables-объекты и файлы:

- 90-easyroute-sets.nft
- 90-easyroute-mark.nft
- 90-easyroute-forward.nft
- 90-easyroute-nat.nft

Hotplug реагирует только на VPN-интерфейсы, выбранные в EasyRoute. Приложение не должно автоматически захватывать произвольный AWG-интерфейс.

## 📦 Требования

- OpenWrt **24.10.x** или **25.12.x**;
- LuCI;
- firewall4 / nftables;
- AmneziaWG;
- dnsmasq с поддержкой nftset.

Установщик поддерживает opkg и apk на соответствующих версиях OpenWrt. Совместимость AWG также зависит от наличия подходящего kernel module для версии OpenWrt и архитектуры роутера.

## 🚀 Установка

Подключитесь к роутеру по SSH под root и выполните:

    wget -qO- "https://raw.githubusercontent.com/evgen4ik600-wq/openwrt-simple-ui/easyroute-stable/openwrt-easyroute-install.sh?$(date +%s)" | sh

После установки: **LuCI → Сеть → 🚀 EasyRoute**.

При обновлении установщик сохраняет существующую конфигурацию EasyRoute и выбранный AWG-интерфейс.

## 🧑‍🦳 Главный принцип интерфейса

> **Пользователь должен знать только две вещи: какой у него VPN и какие приложения он хочет через него отправить.**

Для обычной настройки не нужны знания CIDR, fwmark, nftables, ip rule, routing tables или nftset.

## 🔧 Для опытных

Под капотом поддерживаются несколько AWG-профилей, отдельные fwmark/routing tables, IPv4/CIDR, доменные правила, ручные TXT-списки, URL-списки, маршрутизация устройств по MAC, WAN fallback, блокировка выбранного трафика при недоступности VPN и диагностика маршрутов.

## 🔒 Что EasyRoute специально не делает

- не переписывает произвольные интерфейсы OpenWrt;
- не присваивает себе автоматически любой найденный AWG;
- не удаляет AmneziaWG при удалении EasyRoute;
- не удаляет /etc/config/network;
- не заменяет всю пользовательскую конфигурацию firewall;
- не должен применять firewall-конфигурацию, не прошедшую проверку.

## 🧪 Проверки

GitHub Actions CI проверяет shell-синтаксис, JSON LuCI/RPC ACL, JavaScript LuCI, состав установщика, ключевые инварианты движка и защиту от ряда регрессий.

CI не заменяет испытания на реальном роутере: изменения firewall/network дополнительно проверяются на поддерживаемом OpenWrt-устройстве.

## ⚠️ Статус

Проект находится в активной разработке. EasyRoute управляет сетевой маршрутизацией роутера, поэтому для экспериментов рекомендуется иметь локальный доступ и резервную копию конфигурации.

## ❤️ Зачем существует EasyRoute

OpenWrt очень гибкий, но выборочная VPN-маршрутизация часто требует знаний сетевого администратора. EasyRoute пытается сохранить мощность OpenWrt и убрать эту сложность из повседневной настройки.
